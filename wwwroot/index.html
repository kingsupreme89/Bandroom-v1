Start a Game

Do this while you're still on CFB 27's own team-select screen: pick the same two teams below, then hit GAMETIME right before kickoff. Each team's own saved profile loads automatically, so the right song plays for whichever side actually scores or forces a turnover. You can still switch between them below to tweak songs during the game -- GAMETIME only locks in who's home and away, not which one you're editing. Press Stop Watching at the top when the game ends to unlock and start a new one.
