Get the Free Default Song Pack

This is a one-time download that fills every team with real songs automatically, so you don't have to upload your own. It's about 2.8 GB (2,241 songs), so it can take a few minutes depending on your internet speed.

  1. Click Download below — it opens the download page in your web browser.
  2. Wait for the download to finish (check your browser's download bar).
  3. Come back to Bandroom and click Import when it appears — Bandroom will unpack the file for you automatically.

It only fills in songs for events you haven't already picked one for yourself, so nothing you've already set up gets overwritten. Totally optional — skip it now and add it later from the command palette any time.

Ready to Import?

Once your download has finished, click Import from Zip below and pick the .zip file from your Downloads folder — or, if you already unzipped it (or someone handed you a folder instead), use Import from Folder. Either way Bandroom fills in every team's Sound Bank for you automatically.

  1. Make sure the download from the last step has fully finished.
  2. Click Import from Zip (.zip) or Import from Folder (already unzipped) below.
  3. In the window that pops up, find and select the .zip file or the folder.
  4. Wait for the progress bar — when it's done, every team will have songs ready to go.
