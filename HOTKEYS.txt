hotkey: hunnybunny
-----------------
When the user says "hunnybunny", do NOT answer yet.

First, ask this exact question:
  "Do you want Knowledge King or a Breakdown?"

Then WAIT for the user to pick one.

Knowledge King = The user wants RESEARCH.
  • Explain the thing in detail
  • What is it, how does it work, why does it matter
  • Use plain English, like you're teaching a 10-year-old
  • Be thorough but never sound like a textbook

Breakdown = Something broke and the user wants to know
  what happened.
  • Tell them (1) what went wrong
  • Tell them (2) what you did to fix it
  • Tell them (3) could it happen again or is it really fixed
  • All in plain English, like you're talking to a 10-year-old
  • No code unless they ask for it


hotkey: 523
-----------
The user wants a full project audit. Assign 8 auditors:

  2 auditors → UI (the web interface, app.js, index.html,
                style.css, anything the user sees and clicks)

  2 auditors → Admin (settings, profiles, config, indexing,
                system health, database/cloudflare workers,
                anything that keeps the app running behind
                the scenes)

  2 auditors → Event Triggers (every evaluator, GameWatcher
                OCR, event routing, all state machines, any
                mechanism that detects game events and fires
                audio)

  2 auditors → Audio (AudioPlayer.cs, DSP pipeline, Sound
                Booth, volumes, channels, whistle, trimmer,
                any code that plays or processes sound)

If audio code is present: the Admin auditors must finish
their audit first, then go back and DOUBLE CHECK every other
auditor's work.

Each auditor must go AT LEAST 40 levels deep — trace every
call chain, follow every dependency, check every condition.

For every bug found:
  (1) Diagnose it
  (2) Fix it
  (3) Verify the fix works
  (4) Create a "bug blocker" — a guard, test, or safeguard
      that makes sure it can NEVER happen again

When all 8 auditors finish, present a full report broken
down by each auditor's findings.
