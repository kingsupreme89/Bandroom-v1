🏈 **Bandroom v1.0.54 is out!**

Quick follow-up to v1.0.53 — fixed a few things that only showed up once real people (thanks for the screenshots 🙏) started clicking around the actual app.

**🎨 UI fixes**
- The Assign screen (where you set songs for 1st Down, Touchdown, Field Goal, etc.) was quietly still using plain default Windows-style buttons instead of Bandroom's real dark theme — that's fixed, it now matches the rest of the app.
- Preview/Stop/Volume on those same cards now use the same clean play/stop icon buttons as the Suggested-for-You songs, instead of plain text buttons.
- The bottom ticker bar (the scrolling "X uploaded by Y" strip) was covering the Help & Guide button and cutting off the last bit of content in the side panels — it now stays out of the way.

**🛠️ Crash fix**
- Fixed a real bug where opening some teams' marketplace album (Sound Bank/Trophy Room) could show a totally blank screen with an error toast instead of the songs/images.

Update should grab automatically next time you open the app. If not, grab it here: https://github.com/kingsupreme89/Bandroom-v1/releases/tag/v1.0.54
