# Bandroom — Getting Started Guide

## 1. Download Bandroom

Get the installer from the GitHub releases page:

**https://github.com/kingsupreme89/Bandroom-v1/releases/latest**

Download the file called `BandroomSetup.exe` and run it. It will install automatically — no admin rights needed.

## 2. Where Bandroom lives on your PC

Bandroom installs itself into a folder called **Bandroom** inside your Local AppData folder. You can jump straight there by pasting this into the Windows File Explorer address bar:

```
%LocalAppData%\Bandroom
```

You don't need to go in there for normal use — it's just where the app, your saved songs, and your profile data live if you ever need to find or back them up.

## 3. Open Bandroom

Launch it from the Start Menu (search "Bandroom") or from the desktop shortcut created during install.

## 4. Sign in with Google

On first launch, click **Sign in with Google** in the top corner. Signing in lets you:
- Access the **Marketplace** (browse and download songs/clips other users have shared)
- **Save your profile** across devices
- Track your **stats** (games watched, streaks, top uploads, etc.)

You can use Bandroom without signing in, but the marketplace, profile sync, and stat tracking all require it.

## 5. Choose your favorite team

Open your **Profile**, pick a **Favorite Team**, and optionally set a rival team and upload an avatar. Your favorite team gets a quick-jump star in the header so you can always get back to it fast.

## 6. Universal Profile Override

You can save a **Universal Profile** — a set of song assignments that isn't tied to any one team. When active, it overrides whatever songs are assigned to individual team profiles, so you hear the same set of songs no matter which team you're using. Turn it on/off from the profile screen; turning it off goes back to each team's own assigned songs.

## 7. Setting up a game — step by step

1. On the **team select screen inside the game** (CFB 25/26), click the **Select Matchup** button inside **BandRoom**.
2. From the toolbar, choose **Select Matchup**.
3. Pick your **Away** team and **Home** team.
4. Press **Gametime**.
5. Press **Watching**.
6. Start the actual game inside CFB 25/26.

## 8. Switching teams mid-game

While playing, you can switch between the two teams to change which team's song assignments are active — this lets one person control both bands' cues from one seat.

**Important:** once you press **Watching**, the away/home matchup is locked — you can't change it unless you press **Watching** again to unlock it first.
