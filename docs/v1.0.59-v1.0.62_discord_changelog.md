🏈 **Bandroom v1.0.59 → v1.0.62**

A run of four releases covering real song-pack import bugs plus a full pass on the "make it feel like Spotify/iTunes" redesign.

**📦 v1.0.59 — Default Song Pack songs were invisible**
- Importing a team's pack looked like it went nowhere — the songs *were* landing, there was just nowhere in the Sound Bank view to see them. Fixed: imported pack songs now show up right in that team's Sound Bank album.

**🎯 v1.0.60 — Real filename-matching bugs**
- Found and fixed by actually importing a real 174-file Big Ten conference pack and tracing what broke. Filename-based team/situation matching is now noticeably more accurate.

**🎧 v1.0.61 — Auto-Assign**
- New **Auto-Assign** pill on the event dashboard — fills any empty song slots for whichever team you're editing, one click, any time. Only ever fills gaps, never touches songs you've already picked yourself.
- School names in Sound Bank and the marketplace now glow each team's own color.

**🎨 v1.0.62 — CoverFlow redesign + import feedback**
- The team picker and Favorite Team screen are now a big iTunes/Front Row-style CoverFlow — giant reflective album covers instead of the old compact carousel.
- "Choose a Team" (the full team browser) is now that same CoverFlow instead of a plain grid — browse with the arrows, click the center cover to pick it.
- The background now glows in your active team's color and shifts live as you browse teams in any picker.
- The Default Song Pack list in a team's Sound Bank used to be one long alphabetical wall of songs ("Defense_Drive Starter_4", "_5", "_6"...) — now grouped into collapsible folders by situation type (Kickoff, Drive Starter, etc.).
- Song pack imports used to finish before you could even see a progress bar move. Now shows real per-file progress with filenames scrolling by as it works, and a proper "here's what got imported and where to find it" confirmation that stays on screen until you dismiss it — with an option to turn that off and just get a quiet toast instead.
- Bug fixes: Profile page's ✕ button now works, Escape key closes the Favorite Team picker, side panel no longer overflows on smaller windows, plus a couple of stuck-state edge cases caught in this release's own internal audit.

Update should grab automatically next time you open the app. If not, grab the latest here: https://github.com/kingsupreme89/Bandroom-v1/releases/tag/v1.0.62
