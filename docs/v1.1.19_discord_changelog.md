🏈 **Bandroom v1.1.19 is out — and Bandroom is now testable on Mac!** 🍎

Big session today — the "Team Pot showing when it shouldn't" bug is finally, actually dead (took some real detective work), plus a bunch of quality-of-life stuff and the first real steps toward Mac support.

**🐞 Squashed: Team Pot showing outside HBCU Mode**
This one fought back. Turned out to be a CSS rule quietly overriding the "hide this" instruction the whole time — so the app was always *trying* to hide it correctly, the page just wasn't listening. Fixed for good, and while we were in there, the event card grid now properly fills the screen in normal mode instead of cramping into one column.

**🔊 Popovers that used to render invisible/clipped**
The little volume slider on an event card, and the one on Team Pot songs, could pop up cut off or completely hidden behind the card. Both fixed — same fix already applied to a couple other popovers you probably never noticed were broken.

**🖱️ Rename dialog opening behind My Downloads** — fixed, it now shows up on top like it should.

**✨ Square glow around the header pills (Not Watching / Teams / Save)** — was a hard-edged box instead of a soft round glow. Fixed.

**🎵 Previews now play the whole song**
Clicking Preview on a song used to fade out early at the same point it would in-game. Now it always plays start to finish so you can actually hear the whole thing before assigning it. Team Pot shuffle songs never fade either now — that's a continuous vibe, not a scripted cue.

**📥 Imported songs showing up in Sound Bank right away** — used to need an unrelated team switch to show up. Fixed.

**🔉 Lowered the default master volume** so a fresh setup doesn't come in too hot.

**⭐ NEW: Favorite a song** — star icon next to every song in the picker now, with its own Favorites filter pill, so you can find "that one song" again without digging.

**📦 NEW: Batch add to Team Pot** — ctrl/cmd-click to select a bunch of songs at once, then one click adds all of them to the pot instead of one at a time.

**📖 NEW: "What triggers each situation?" in the Help Guide** — a full plain-English reference for every single event card (what actually fires it, auto vs. manual, why some cards look duplicated). In-app now, under Help & Guide.

🍎 **Mac support — early testing build, not a full release yet**

Bandroom now runs on Mac! This is NOT a downloadable installer yet — it's a from-source build for testers who don't mind using Terminal. Here's the whole process in plain English:

**Before you start:**
1. You need a Mac and a Wi-Fi connection.
2. Open **Terminal** (⌘+Space, type "Terminal", hit Enter).
3. Install the .NET 10 SDK if you don't have it: go to https://dotnet.microsoft.com/download/dotnet/10.0, download the macOS installer for your chip (Apple Silicon or Intel), run it, then close and reopen Terminal.
4. Check it worked by typing `dotnet --version` — it should print something starting with `10.`

**Get the app onto your Mac:**
Copy the whole Bandroom project folder onto your Mac (USB stick, shared network folder, or a zip you email/Dropbox to yourself) and put it in your home folder, so the path is `~/Bandroom`.

**Build it:**
```
cd ~/Bandroom
dotnet build src/Bandroom.Mac/Bandroom.Mac.csproj
```
Wait for `Build succeeded.` at the end.

**Run it:**
```
dotnet run --project src/Bandroom.Mac/Bandroom.Mac.csproj
```
A small window opens and your browser pops open automatically to `http://localhost:18765` — that's Bandroom.

**To stop it:** press `Ctrl+C` in Terminal.

**If something breaks:** the most common issue is `dotnet: command not found` (SDK isn't installed — see step 3 above) or the browser not opening (just type `http://localhost:18765` into your browser's address bar manually).

This is early — screen-watching/OCR support on Mac is still being worked on, so treat this as "does the app itself open and work," not a full replacement for the Windows version yet.
