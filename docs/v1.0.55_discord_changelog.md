🏈 **Bandroom v1.0.55 is out!**

**🏟️ New: 50 FCS schools added to the roster**
- The 50 most popular FCS programs (North Dakota State, Montana, Montana State, South Dakota State, Villanova, Furman, and more) now ship as real teams, right alongside the ~140 FBS schools -- same Team picker, same Set Matchup eligibility, same automatic in-game color detection as everyone else. No extra steps, they're just there.
- Don't see your school even in that list? "Add School" still lets you create a fully custom team (name + colors), same as before -- just set its logo afterward from the Team picker's pencil icon.
- See the new "Don't see your team? Add it yourself (TeamBuilder)" section in Help & Guide for the full walkthrough.

**🐛 Bug fix: some teams silently got 0 songs from the Default Song Pack**
- Found and fixed a bug from the last security pass where a team name containing a period (like a custom school with "St." in it) could get mangled before Bandroom looked up its folder in the Default Song Pack -- so that team silently imported zero songs while every other team worked fine. This is why some players needed help from others while their setup seemed totally normal to us. Fixed at the root (`ConfigStore.ImportDefaultPackForTeam`) so every team name matches correctly again.

**📖 Help & Guide additions**
- New "No sound is playing? Try this, in order" troubleshooting checklist -- five plain-language steps to run through before asking for help.
- New "An update broke something -- how do I go back to an older version?" section -- step-by-step instructions to revert to any past release from GitHub if a new update ever causes trouble, with reassurance that your songs/settings are never lost by doing this.
- New "Don't see your team? Add it yourself (TeamBuilder)" section explaining the Add School flow end to end.

**🎨 UI: clearer Default Song Pack download/import dialogs**
- Rewrote the download and import prompts into plain numbered steps instead of one dense paragraph, and made the header bigger and styled to match the Bandroom logo, with larger body text throughout so the instructions are easy to read at a glance.

Update should grab automatically next time you open the app.
