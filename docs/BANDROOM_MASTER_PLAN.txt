================================================================================
  SECTION D: QUICK START — HOW TO BUILD & RUN ON MAC
================================================================================

1. Copy c:\Bandroom to your Mac (USB, AirDrop, Google Drive)
2. Install .NET: /bin/bash -c "$(curl -fsSL https://dot.net/v1/dotnet-install.sh)"
3. Install OCR: pip3 install pyobjc-framework-Vision
4. Terminal: cd Bandroom/src/Bandroom.Mac && dotnet run
5. Open browser to http://localhost:18765
6. Grant Screen Recording permission when prompted
