## Bugs Found & Fixed During Audit

### 🔴 CRITICAL — Fixed: UserIsHome Never Set
**File:** `WebMainForm.cs` line 221  
**Symptom:** Every side-aware evaluator (OffenseDownHelper, DefenseHelper, KickoffHelper, DriveStarterHelper, etc.) would attribute events to the WRONG team.  
**Root cause:** `GameWatcher.UserIsHome` property was declared but never assigned. Defaulted to `false`.  
**Fix:** Added `_watcher.UserIsHome = true;` in `SetGameTeamsFromWeb()`.  
**Impact:** All 7 evaluators using `UserHasPossession` were silently broken. Now fixed.

### 🟡 NOTED — Not Fixed: Duplicate Event Paths
**File:** `WebMainForm.cs` lines 844-851, 882-940  
**Symptom:** Old handlers (`OnDownChanged`, `OnRegionChanged`, `OnTackleForLoss`) still fire alongside new `OnEngineEventsDetected`.  
**Mitigation:** `AudioPlayer.FireCooldown` (20s per-path) prevents actual double-playback.  
**Recommendation:** Gate old handlers behind a flag or remove them when confident in new engine.

### 🟡 NOTED — Pre-existing: TimeoutHelper EventKey Format
**File:** `TimeoutHelper.cs` lines 18-25  
**Issue:** EventKeys use index-based names (`2ND_TIMEOUT_4_REMAINING`) instead of the standard "Category: Name" format. These won't match any `TriggerEntry.Event` string unless manually created with those exact keys.

## Known Limitations (Pre-existing, Not From This Session)

| Limitation | Impact |
|-----------|--------|
| No score OCR region | HomeScore/AwayScore always 0 → FieldGoalPATHelper, SafetyHelper, GameStateEventHelper.Victory never fire |
| No clock OCR region | TimeRemainingSeconds always 0 → Iced Game, 2-min warning variants never fire |
| No yard line OCR region | YardLine always 0 → Midfield/BigGain position variants always fire (fallback path) |
| No timeout OCR indicator | AwayTimeoutsRemaining always 6 → TimeoutHelper never fires |
| Flag/banner regions uncalibrated | FxW=0 → PenaltyHelper, banner situations skipped by OCR |
